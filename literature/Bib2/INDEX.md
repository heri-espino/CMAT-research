# CMAT literature corpus — Bib2

Compact retrieval index for the second literature batch.

## Retrieval order

1. Start here and identify the relevant record ID.
2. Read only the targeted file in `extracted/`.
3. Use `references/` only for citation chaining or bibliographic verification when a separated reference file exists.
4. If the Markdown extraction is ambiguous, corrupted, or insufficient for an exact numerical/table/figure claim, inspect the corresponding source PDF in `pdf/`.
5. **Bib2 intentionally contains no Docling PNG/table/figure assets.** The PDFs are the visual/source-of-truth fallback.
6. Do not infer coefficients, p-values, confidence intervals, sample sizes, effect sizes, or table values from a corrupted extraction.
