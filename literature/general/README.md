# General CMAT literature

This folder is the cross-project conceptual map for literature that informs the CMAT research programme as a whole.

It is not a separate physical library. Sources remain under `../library/`; this folder contains scientific indices and synthesis/retrieval notes.

Primary themes:

- mathematics/statistics support;
- academic help-seeking;
- student engagement, transition, belonging and support;
- incentives and behavioural persistence;
- observational inference, selection and confounding;
- academic performance/measurement;
- institutional and human-capital context.

Start with `INDEX.md`, then use `../library/CATALOG.md` to locate the preferred source record. Paper-specific literature roles are maintained under `../papers/`.
