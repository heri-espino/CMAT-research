# General CMAT literature

This folder contains the cross-project conceptual map for literature that informs the CMAT research programme as a whole.

It is not a separate physical library. Sources remain in `../library/source_material/`; this folder contains scientific indices and synthesis notes.

Primary themes:

- mathematics/statistics support;
- academic help-seeking;
- student engagement and first-year transition;
- observational inference, selection and confounding;
- academic performance/measurement;
- institutional and human-capital context.

Start with `INDEX.md`.
# General literature map

This folder is a thematic navigation layer over `../library/`. It contains no physical article copies.

Use it when the question concerns the CMAT research programme broadly rather than one manuscript. Paper-specific literature roles are maintained under `../papers/`.

## Rule

Every literature ID listed here resolves to the canonical physical record in `../library/articles/<id>.md` and, where available, the corresponding PDF/references/assets.
