# General literature index

This index groups sources by cross-project scientific function. It is a retrieval/thematic layer over the shared canonical library under `../library/`.

Categories are not mutually exclusive. Use `../library/CATALOG.md` to locate the preferred canonical record and exact source path.

## 1. Mathematics and statistics support

- `mullen_2024_mathematics-statistics-support-review` — **core** broad review of mathematics/statistics support evidence; use for field positioning and recurring limitations in support-centre evaluation.
- `lawson_2019_mathematics-support-literature-review` — **core** literature synthesis; useful for institutional context and prior outcomes/methods.

## 5. Observational inference, selection and confounding

- `rosenbaum_1983_propensity-score-causal-effects` — **methods** foundational propensity-score work.
