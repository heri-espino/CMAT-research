# Literature provenance

The canonical library consolidates two historical ingestion batches that previously lived under migration-oriented names (`literature/Bib/`, `literature/Bib2/`, and an accidental duplicate `literature/Bib2-2/`). Those names are preserved in Git history only and are not part of the active architecture.

## Current canonical inventory

- 50 Markdown article/version records.
- 49 source PDFs in `pdf/`.
- separated reference-list files where available.
- Docling visual assets only for the original archived subset; the later expansion intentionally omitted its redundant PNG assets.

The `kahu_2018_student-engagement-educational-interface` record is available as Markdown but does not currently have a source PDF in the consolidated library.

Distinct versions such as the Damgaard alternative/published copies and the Oreopoulos working-paper/published records are intentionally retained as separate version records until a bibliographic review decides otherwise.

No scientific analysis or student data are stored in this directory.
