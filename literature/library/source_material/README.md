# Source material

This directory preserves the original literature source material while the scientific organization lives one level above in `literature/general/` and `literature/papers/`.

## `visual_corpus/`

Historical source set containing:

- source PDFs;
- extracted Markdown;
- separated references;
- Docling visual assets.

## `pdf_markdown_corpus/`

Historical source set containing:

- source PDFs;
- extracted Markdown;
- separated references;
- no visual assets by design.

These folders preserve provenance and efficient retrieval. They are not separate bibliographies and should not be cited as conceptual categories in manuscripts.

Use `../CATALOG.md` to identify preferred records and the paper/general indices to determine relevance.
