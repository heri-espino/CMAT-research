# Paper 5 literature — longitudinal support trajectories

Working manuscript: **Longitudinal Trajectories of Mathematics Support Use Across the Undergraduate Degree**.

Canonical portfolio: `../../../docs/PUBLICATION_PORTFOLIO.md`.

This folder is a scientific view over the shared library, not a separate physical corpus.

## Core question

What recurring trajectories of formal mathematics-support use appear across students’ undergraduate course sequences, beyond a single MU→Calculus transition?

## Literature families

- longitudinal academic help-seeking;
- repeated mathematics-support use;
- educational transitions and persistence;
- sequence analysis / state-transition models;
- learning analytics using longitudinal educational traces;
- trajectory clustering and learner-state modelling;
- missingness/coverage in administrative longitudinal data;
- ethics, privacy and responsible use of learning traces.

This is a future paper. The literature view should evolve only after the available longitudinal data structure is audited; do not prematurely optimize the bibliography for a specific trajectory method.
