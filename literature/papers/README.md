# Paper-specific literature views

These folders organize the shared research library around manuscript-specific questions. They do not contain duplicate PDFs or duplicate extracted articles.

- `paper1_ppa_persistence/` — incentives, incentive removal, persistence of support-seeking, engagement, first-year transition and mathematics-support context.
- `paper2_mu_performance/` — mathematics-support use, academic performance, help-seeking, selection, classroom heterogeneity and observational robustness.

A source may appear in both indices when it legitimately serves both papers. Physical source material remains under `../library/`.

Each paper view should maintain:

- `README.md` — scope and research question;
- `INDEX.md` — curated sources with role/priority notes;
- `MISSING_LITERATURE.md` — targeted gaps for future searching.
