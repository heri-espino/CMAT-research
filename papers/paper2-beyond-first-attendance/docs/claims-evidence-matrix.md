## Hierarchy, decisions and release gate

- **Primary inferential anchor:** C01–C05 (adjusted Wald/Holm and benchmark); report the unadjusted baseline as context and keep exact contrast families explicit.
- **Supplementary inference/sensitivity:** C06–C10, C18, C20. Explain family definitions, conditioning, top-coding, observed vs imputed outcomes and modeling assumptions.
- **Exploratory model analysis:** C11–C17, C19. These test distributional adequacy, penalized parsimony, fit allocation or retrospective prediction—not the historical frequency null.
- **Descriptive:** component/outcome composition and raw grade distributions (C09, C21).
- **Unresolved / excluded:** no latent classes, policy discontinuity, causal attendance effects, equivalence, causal Shapley importance, semester-start prediction, or unexecuted PPA/modality claims (C22–C23).

**Certification scope:** The referenced CSVs, notes and run manifest were opened on GitHub at the pinned branch heads. This is a *remote-artifact/provenance audit*, not an independent reproduction from controlled workbooks; no new p-values or confidence bounds were calculated. A PPA-run commit and CSVs, subgroup denominator/overlap checks and an administrator's manuscript review remain release gates.
