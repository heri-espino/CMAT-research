# Reports

Technical and internal-facing reports.

## Canonical technical report

The technical report is intended to present the complete empirical and methodological record for statistical review. It should:

- explain mathematical/statistical methods in detail;
- present **all validated discoveries**, not only those destined for publication;
- distinguish descriptive, associational and causal claims carefully;
- keep the proposed publication split until the end;
- map every reported number to a reproducible aggregate output.

## Current status

`reports/technical_report_v8/` is a preserved historical imported snapshot. It should not be silently overwritten. After methodology reconciliation, a short-lived report branch should build `reports/technical_report/` as the canonical clean report.
