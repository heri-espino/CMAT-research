# CMAT methodology report

This directory contains the methodology-focused technical report used for statistical review. It presents the complete current empirical and methodological record first and discusses the proposed publication split only near the end.

## Reproducible build

The canonical runner is:

```bash
python code/experiments/methodology_report.py
```

It uses the shared scientific pipeline plus the methodology-specific functions restored from the validated methodology snapshot to regenerate the aggregate CSV outputs and figures used by this report. It then stages the generated CSV/PNG assets into this directory and rebuilds the `latex_*.tex` table snippets from those CSVs.

Useful modes:

```bash
# Validate paths/import structure without controlled data
python code/experiments/methodology_report.py --check

# Run with explicit new data extracts
python code/experiments/methodology_report.py \
  --materias /controlled/path/Materias.xlsx \
  --asesorias /controlled/path/Asesorias.xlsx

# Regenerate, stage, and compile the report
python code/experiments/methodology_report.py --compile
```

Generated working outputs live under `code/outputs/methodology_report/` and are ignored by Git. The runner writes `build_manifest.json` with input SHA-256 values, cohort counts, staged assets and provenance metadata.

The runner deliberately preserves and labels these report assets as external later-stage snapshots rather than silently claiming they are methodology-pipeline outputs:

### Narrative prose after a data update

Tables, figures and LaTeX table snippets are regenerated. The prose in `methodology_report.tex` still contains explanatory sentences with some embedded numerical values. When a new institutional-data extract changes results, review those sentences against the regenerated outputs before treating the compiled PDF as updated. Do not manually change a number without tracing it to the generated CSV/output.

## Methodological content

The report documents the later methodology corrections and extensions, including:

1. official degree programme from the academic record linked by student ID;
2. BV/RT/BA primary continuous imputation using within-classroom KDE below 7.5 with `scipy.stats.gaussian_kde(..., bw_method=None)` / Scott default, with empirical resampling for non-empty degenerate pools and uniform only as the empty-pool fallback;
3. exact performance groups `0/1/2/3/4+`, all 10 Games–Howell pairs and all 10 adjusted FE+Holm pairs;
4. exact counts 0–12 with explicit diagnosis of the sparse 8–12 tail;
5. peak/periodicity analysis for all CMAT records and separately for first-MU students during MU;
6. degree-programme summaries and use-vs-performance scatterplots for three distinct populations;
7. the N=4,211 future-Calculus cohort treated as a selected progressor sensitivity rather than replacing the full N=6,627 first-MU cohort;
8. explicit discussion of longitudinal analysis, ecological inference limits, cluster-robust inference, multiplicity and propensity-score limitations.
