## Literature priorities

- mathematics/statistics support evaluation and academic performance;
- who uses mathematics support and selection into attendance;
- any-use versus frequency/dose comparisons;
- observational versus encouragement/experimental designs;
- classroom/instructor adjustment and outcome comparability.

Use `INDEX.md` for the current source map and `MISSING_LITERATURE.md` for targeted acquisition gaps.

## Interpretation boundary
