## Language and style convention

All text embedded in current manuscript figures is English. The figures use `University Mathematics (MU)` for the first course, `Calculus I` for the later course, `CMAT visits` or `CMAT use` for recorded support encounters, and `major` only when degree programme wording is needed. The figures use the shared `cmat_analysis.visualization.set_style()` entry point and otherwise keep a restrained paper-oriented design.

## Optional academic-performance figure

No additional `Z_{Calc}` figure is included in the current manuscript. The academic-performance model is explicitly secondary to the paper's behavioural-persistence outcome, and a fifth coefficient plot would largely duplicate the numerical result already reported in prose while increasing the visual weight of a non-primary outcome. This decision can be revisited if the paper's emphasis changes, but adding such a figure is not necessary for the present argument.
